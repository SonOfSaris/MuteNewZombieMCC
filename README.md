# MuteNewZombieMCC

Mutes the "New Zombie" announcer in Halo 3 Infection (Halo: The Master Chief Collection, PC).

Download and extract this repo, close the game, then double-click `Mute New Zombie.bat`. To undo, run `Restore New Zombie.bat` or verify the game files in Steam.

It only changes that one sound in your own `halo3\fmod\pc\sfx.fsb`; no game files are included. Use at your own risk: it's unknown how MCC's Easy Anti-Cheat treats the edited file.
